# Changelog

## [0.1.1] - 2026-08-13

### Added

- 新增电脑端文件与文件夹拖入会话发送，复用加密分块和超大文件传输链路。
- 新增历史消息手动清理与二次确认，清理本地附件并通过 WebDAV 删除墓碑防止消息恢复。

### Fixed

- 修复会话页右上角搜索和更多按钮缺少交互的问题，并补充键盘与焦点行为。
- 将会话搜索改为按钮下方的浮层输入框，并提高标题栏操作菜单的堆叠层级。
- 搜索输入框聚焦时保持边框与阴影样式不变，减少不必要的视觉跳动。

## [0.1.0] - 2026-08-13

### Added

- 新增 macOS、Windows、Linux 与 Android、iOS 浏览器之间的聊天式实时互传。
- 支持文本、链接、图片、任意格式文件及文件夹发送，并提供内容一键复制与附件打开。
- 新增二维码一次性密钥、6–12 位匹配码、错误锁定、设备授权撤销及 AES-256-GCM 会话加密。
- 新增 4 MiB 流式分块、大文件失败重试、SHA-256 完整性校验及最高 1 TB 接收配置。
- 新增加密 WebDAV 离线同步、附件分块同步和删除墓碑，避免离线设备恢复已删消息。
- 新增移动端非安全上下文加密后备与 IndexedDB 超大文件暂存能力。

### Fixed

- 修复通过 ZTools 开发者工具加载 `dist/` 时错误跳转到未启动的 Vite 开发地址，导致插件白屏的问题。
- 修复 ZTools preload 使用浏览器数字计时器句柄时调用 `unref()` 导致服务启动失败的问题。

### Security

- 局域网服务限制为私有地址访问，并提供 CSP、防嵌入、内容类型保护和会话/传输资源限额。
- 配对连续失败 5 次后锁定 10 分钟，成功配对后立即轮换二维码中的一次性密钥。
