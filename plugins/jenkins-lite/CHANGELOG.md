# Jenkins Lite - 功能清单

一款轻量级的 Jenkins 辅助工具，帮助开发者快速检索任务状态、监控构建进度并秒级触发构建。

## 核心功能

### Jenkins 实例管理
- 添加、编辑、删除多个 Jenkins 实例
- 快速切换不同 Jenkins 服务
- 自动保存实例配置

### 任务列表
- 查看所有 Jenkins Jobs
- 支持 Folder 嵌套结构
- 按视图筛选 Jobs
- 搜索 Jobs
- 显示任务状态（成功/失败/运行中/禁用等）

### 收藏功能
- 收藏常用 Jobs
- 自动记录收藏时的视图
- 点击收藏快速跳转到对应视图

### 构建管理
- 一键触发构建
- 构建确认弹窗
- 实时构建状态监控

### 构建历史
- 查看 Job 构建历史
- 显示构建开始/结束时间
- 显示构建持续时间
- 点击跳转到 Jenkins 构建页面

### 通知提醒
- 构建触发成功通知
- 构建触发失败通知
- 实例添加/删除通知

## 技术特性

- 基于 Vue 3 + TypeScript 构建
- 支持暗黑模式
- 响应式设计
- 数据本地持久化存储
- 支持多实例切换

## 快捷指令

- `jenkins` - 打开 Jenkins Lite
- `jenkins lite` - 打开 Jenkins Lite
- 任意文字 - 搜索 Jenkins 任务
