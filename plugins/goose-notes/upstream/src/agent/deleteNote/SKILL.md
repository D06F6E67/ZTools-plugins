# 删除笔记

## 适用

- 用户明确要求删除一个或多个页面。
- 用户要求完成其他操作后删除来源页面。

## 执行

- 只删除用户明确指定的页面。
- 页面 id 已明确时直接调用 `deletePages`。
- 目标不明确时先调用 `listPages` 或 `searchNotes` 定位。
- 不根据相似标题猜测页面。
- 批量删除时一次传入全部页面 id。
- 删除父页面会连同子页面一起删除。
- 新建汇总页后删除来源页时，不得把新页面加入删除列表。

## 限制

- 不删除文件夹、锁定页面或其他笔记本中的页面。
- 不执行永久删除。
- 工具部分成功时如实说明已完成和未完成的范围。
